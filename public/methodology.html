METHODOLOGY

Every data source, formula, and decision that produces today's word. Nothing hidden. Nothing invented.

Data Pipeline
L1
Ingestion
Python cron fetches raw JSON/RSS from 5 free sources every 6 hours. Raw values stored with timestamps in Supabase.
L2
Normalization
Each category converts heterogeneous data into a 0–100 Index Score. 50 = neutral baseline.
L3
Weighted Synthesis
Category scores combined with fixed weights. Conflict (28%) carries the highest weight as the most acute human impact signal.
L4
Ontology Mapping
Composite scores matched against a curated dictionary of World State Words using deterministic trigger conditions.
L5
AI Explanation
The word + top-3 drivers passed as JSON to a free-tier LLM. Produces exactly one sentence. No internet access, no invention.
